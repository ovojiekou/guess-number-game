# 猜数字小游戏

这是一个适合 Python 初学者的命令行小游戏。电脑会随机想一个 1 到 100
之间的整数，玩家通过输入数字来猜测答案，程序会提示“大了”或“小了”，
猜中后显示答案和猜测次数。

## 功能

- 电脑随机生成 1 到 100 之间的整数
- 玩家可以反复输入猜测
- 每次猜测后提示“大了”或“小了”
- 猜中后显示正确答案和总猜测次数
- 对非数字和超出范围的输入给出提示，程序不会崩溃

## 运行环境

- Windows 10 / 11
- Python 3.8 或更高版本
- 不需要安装第三方库，只使用了 Python 自带的 `random` 模块

## 如何运行

1. 按下键盘上的 `Win + R`，打开“运行”窗口。
2. 输入 `cmd`，按回车，打开命令提示符。
3. 在命令提示符中切换到项目文件夹：

   ```bat
   cd /d D:\code\play_do\first
   ```

4. 运行程序：

   ```bat
   py guess_number.py
   ```

5. 按提示输入数字。输入 `Ctrl + C` 可以提前退出游戏。

> 如果提示“找不到 py”，说明 Python 没有添加到 PATH。可以先检查
> `python --version`，或者重新安装 Python 时勾选
> “Add Python to PATH”。

## 程序逻辑

1. 使用 `random.randint(1, 100)` 生成答案。
2. 使用 `while True` 让游戏持续运行，直到玩家猜中。
3. 使用 `input()` 读取玩家输入，并用 `isdigit()` 检查是否为数字。
4. 使用 `if / elif / else` 比较猜测值与答案：
   - 猜测值更大：提示“大了”
   - 猜测值更小：提示“小了”
   - 两者相等：提示猜中，并结束循环
5. 使用 `guess_count` 记录有效猜测的次数。
